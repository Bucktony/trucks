# Trucks! 🚚

A tiny top-down construction game for little kids. Arrow keys drive, mouse clicks pick.
v2: a big site (about 3 screens) with dirt roads, a roundabout and a camera that follows the truck.
Every vehicle helps build ONE BIG TOWER on the roundabout island, one visible piece per delivery
(18 steps: dig, sand, foundation, dirt, stone walls, steps, 3 floors of steel + concrete, windows,
door, red top, light and flag). The garage highlights the truck that's needed next; the glowing ring,
edge-of-screen arrow and minimap show where to go. Progress is saved in the browser.
No losing, no timers.

Static HTML + JS, no external assets. Sounds are WebAudio; voice uses the browser's speechSynthesis.
The player's name and truck colors are stored only in the browser's localStorage.
